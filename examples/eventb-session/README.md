## 脱敏范围

案例中的本地路径、用户名、个人标识、会话标识、邮箱和潜在凭据均已替换为占位符。原始 JSONL 和原始提示文本不随仓库发布。

## 复现说明

这些文件是公开展示快照，用于说明输出格式和分析结果。它们不包含原始会话，因此不能单独重建完整分析过程。
